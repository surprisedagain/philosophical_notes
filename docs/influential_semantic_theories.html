Davidsons truth theories

What do we want from a theory of semantics? (An explanation of how it is that some things represent other things?) Davidson claims that all we want is to capture sentences such as the following as theorems.

  1. “Amelia sings” is T (in language L) if and only if Amelia sings.

Now clearly the “if and only if” is an truth functional connective, so if we replace either side of (1) with a sentence with the same truth value the truth value of (1) will not be changed. So

  1. “Amelia sings” is T (in language L) if and only if grass is green.

is true and just as good a way of specifying the truth value of (1)

In cases where the interpreter (devisor of the semantic theory) knows that a statement of L is true(/false) the T theory may as well be something like:

“Amelia sings” is T in L

But there will be many sentences of L whose truth value is unknown to the devisor of the theory, and even for them she needs to come up with some statement in the home language that she is justified in believing has the same truth value as the sentence of junglese.

Davidson's claim is that we must have a systematic way of constructing these truth value matching theorems. And that any systematic way of doing so will have to get the meanings right. We can match up a finite number of sentences of junglese and the home tongue by ad hoc means, but to be confident in the infinitely many matches of the theory is required to capture as theorems it will have to (in all but a finite number of cases[or types of case]) match sentences we normally view as having the same meaning. His justification for this claim is obscure to me.
